Funciones actuales del launcher

QUÉ HACE BOOST PC HOY

La web refleja el comportamiento real de la versión actual: sin promesas de FPS garantizados, sin cierres forzados y con separación clara entre mantenimiento, diagnóstico y optimizaciones PREMIUM.

PREMIUM

⚡ OPTIMIZAR AHORA

Aplica el perfil de rendimiento seleccionado. EQUILIBRADO realiza además un análisis previo y un mantenimiento seguro antes de confirmar la operación.

ANÁLISIS → CAMBIO → VERIFICACIÓN → RESTAURACIÓN
ANÁLISIS PREVIO

Lee CPU, RAM, disco, procesos, interferencias, Steam, batería, térmica, Game Mode, almacenamiento, DNS e inicio sin modificar nada durante el diagnóstico.

PRIORIDAD DEL JUEGO

Detecta ejecutables reales dentro de Steam y ajusta su prioridad según el perfil. EQUILIBRADO usa prioridad Above Normal; COMPETITIVO puede usar High, nunca Realtime.

GAME MODE

Los perfiles Gaming y Competitivo pueden activar Windows Game Mode cuando está disponible y Neith conserva el estado anterior para restaurarlo.

PLAN DE ENERGÍA

Gaming, Competitivo y Trabajo pueden usar alto rendimiento cuando procede. EQUILIBRADO conserva el plan actual. En batería o con protección térmica Neith evita cambios agresivos.

CARGA EN SEGUNDO PLANO

Gaming y Competitivo pueden bajar de prioridad únicamente procesos de una lista segura cuando la telemetría demuestra carga relevante. Neith no cierra aplicaciones automáticamente.

MANTENIMIENTO EQUILIBRADO

Limpia TEMP del usuario, D3D Shader Cache, Windows Temp antiguo y cachés regenerables de Chrome, Edge y Firefox cuando esos navegadores están cerrados.

PAPELERA CON CONFIRMACIÓN

Neith calcula previamente tamaño y elementos. Solo la vacía si tú eliges expresamente “Optimizar + vaciar papelera”.

CACHÉ DNS

El mantenimiento EQUILIBRADO renueva la caché DNS. Cambiar servidores DNS es una herramienta separada y nunca ocurre silenciosamente dentro de Optimizar ahora.

PROTECCIÓN DE DATOS

Contraseñas, cookies, sesiones, perfiles, historial, marcadores, Local Storage e IndexedDB están fuera de la lista de borrado.

RESTAURACIÓN

Prioridades, Game Mode y plan de energía modificados por una sesión de Boost se registran para poder recuperar su estado anterior.
