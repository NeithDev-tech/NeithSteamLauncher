NEITH://NÚCLEO/IDENTIDAD

Neith es un launcher para Windows que centraliza cuentas, biblioteca y utilidades gaming en una interfaz unificada, con módulos independientes para distintas funciones del ecosistema.

NEITH://NÚCLEO/DESCARGA

El botón de descarga de la web dirige a la última versión oficial publicada en el canal de releases del proyecto.

NEITH://NÚCLEO/COMPATIBILIDAD

La distribución oficial está orientada a equipos Windows 10 y Windows 11 de 64 bits.

NEITH://MEMBERSHIP/TIERS

La estructura comercial separa un nivel Gratis con acceso esencial y un nivel Premium destinado a funciones avanzadas. La disponibilidad definitiva de cada función se mostrará en la página de planes cuando el sistema comercial quede activado.

NEITH://MEMBERSHIP/STATUS

El panel privado de usuario está preparado para mostrar el estado de la cuenta y distinguir visualmente entre acceso Gratis y Premium.

NEITH://MEMBERSHIP/BILLING

La web ya contiene la estructura preparada para integrar facturación, pero la activación comercial debe considerarse operativa únicamente cuando Neith publique oficialmente el flujo de compra.

NEITH://CONFIG/HOUR-BOOST

Hour Boost dispone de una interfaz específica para gestionar sesiones y los juegos asociados a cada cuenta, con estados de actividad visibles desde el launcher.

NEITH://CONFIG/FREE-GAMES

El módulo está orientado a promociones temporales y oportunidades gratuitas, diferenciándolas de una simple lista de títulos gratuitos permanentes.

NEITH://CONFIG/DOCS

La sección Ayuda contiene documentación complementaria del proyecto y seguirá ampliándose a medida que se publiquen nuevas funciones.
