NEITH OFFICIAL WEB — V25

CORRECCIONES PRINCIPALES
1. Menú de usuario: el control de cuenta deja de competir entre varios listeners. header-controller.js captura el clic una sola vez y auth.js decide, usando la sesión real, si abre Acceso Neith o el menú de cuenta. No existe navegación heredada al Dashboard desde el nombre del usuario.
2. ES/EN global: ampliado el diccionario para estados dinámicos, controles, accesibilidad, panel privado y textos generados por JavaScript. Se traducen también atributos value/data-label/data-title/data-description.
3. Sincronización de idioma: tras neith:languagechange se ejecuta una segunda pasada en requestAnimationFrame para recoger módulos que reescriban contenido en el mismo ciclo del cambio de idioma.
4. Cache bust V25 en auth.js, header-controller.js e i18n.js para impedir que el navegador reutilice la lógica V24.
5. Se conserva el diseño y la funcionalidad existente. No se implementan pagos reales.

PRUEBAS RECOMENDADAS
- Ejecutar _PROBAR_WEB.bat.
- Cambiar ES -> EN y navegar por todas las pestañas; repetir EN -> ES.
- Con sesión iniciada, pulsar el nombre: debe abrir/cerrar el menú sin navegar.
- Sin sesión, el mismo control debe abrir Acceso Neith.
