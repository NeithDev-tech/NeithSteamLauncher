05 // FAQ

PREGUNTAS.
RESPUESTAS CLARAS.

Lo esencial sobre Neith antes de descargarlo.

¿Qué es Neith Steam Launcher?

Un launcher para Windows que reúne cuentas, biblioteca, Hour Boost, Boost PC, logros, juegos gratis, actualizaciones y otras herramientas dentro de una misma interfaz.

¿Dónde se descarga la versión oficial?

Desde la última release oficial publicada en el repositorio de GitHub de Neith.

¿Funciona en Windows 10 y Windows 11?

Sí. La distribución oficial está orientada a Windows 10/11 x64.

¿Qué es Hour Boost?

El módulo de Neith para gestionar sesiones de boost de horas desde una interfaz integrada.

¿Qué hace Boost PC?

Ofrece monitorización y herramientas de optimización presentadas dentro del diseño gaming de Neith.

¿Qué muestra Juegos Gratis?

Promociones relevantes de juegos gratuitos detectadas por Neith y conectadas con su sistema de notificaciones.

¿Habrá versión Free y Premium?

La web está preparada para incorporar información de planes en el futuro sin convertir la licencia en una dependencia del funcionamiento básico del sitio.

¿Cómo se actualiza Neith?

Las releases oficiales permiten distribuir nuevas versiones y el launcher incluye su propio flujo de actualización.
